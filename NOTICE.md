# Third-party notices

## What this library is, in copyright terms

`yjs-php` is an independent implementation of a wire format. It reads the
published behavior of lib0 and Yjs and reproduces it in PHP. It does not
contain, translate, or transliterate their source.

The distinction matters and is worth keeping deliberate:

- **Interoperating with a format** is what this package does. Byte layouts,
  type tags, and encoding rules are facts about a format.
- **Porting an implementation** — translating a function statement by statement
  and carrying its structure across — would make the result a derivative work
  and would carry the original license with it.

## Policy

1. Any file that *is* derived from third-party source must carry that project's
   copyright notice and license header at the top of the file, and must be
   listed in the table below. There are currently no such files.
2. Comments may name a lib0 or Yjs function to say which behavior is being
   matched, and may quote a short constant or byte layout. They must not
   reproduce the body of a function.
3. Test fixtures generated by running third-party code are outputs, not source.
   They are committed under this project's license, and the packages that
   produced them are recorded in `compatibility/profile-1.md`.
4. If a future phase does need to port real source, do it in its own file, say
   so in that file's header, add it to the table, and keep it out of files that
   are independently written.
